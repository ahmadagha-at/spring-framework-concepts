# Spring Framework Concepts

A step-by-step deep dive into the core concepts of the Spring ecosystem and its modules.

## About This Repository

This repository is a structured collection of articles about the theoretical foundations of Spring.

Its purpose is to explain not only how Spring is used, but also how its core concepts work and why they are important. The articles begin with the fundamentals and gradually move toward more advanced topics across the Spring ecosystem.

Each article focuses on a specific topic and presents it in a clear and structured way. Where appropriate, future articles may also include practical examples that connect the theory to real-world application development.

## Topics

The series will cover topics such as:

- Spring Framework and Spring Boot
- Spring Core
- Inversion of Control and Dependency Injection
- beans, scopes, and the bean lifecycle
- Spring Boot auto-configuration
- Spring MVC
- Spring Data
- Spring Security
- testing Spring applications
- additional modules and advanced concepts

## Goal

The goal of this repository is to build a well-organized knowledge base for understanding the Spring ecosystem—from its core principles to its specialized modules.

It also documents my continuous learning process and my growing understanding of Spring-based application development.

## Sources

The articles are based primarily on the official Spring documentation. Additional educational sources may be used to provide alternative explanations and perspectives. Each article contains its own list of references.
